8. PROMPTS DE MELHORIA DO BOT

O objetivo desta seção NÃO é criar perguntas genéricas sobre
os dados.

Seu objetivo é identificar oportunidades para melhorar o bot
que realiza os atendimentos.

Analise principalmente as conversas e o comportamento da IA.

Para cada oportunidade encontrada, crie um prompt/instrução
que poderia ser utilizado pela equipe responsável pelo bot
para melhorar seu comportamento.

Priorize:

- respostas inadequadas
- respostas repetitivas
- falhas de comunicação
- informações inconsistentes
- problemas durante negociação
- tratamento de objeções
- falhas durante geração do contrato
- problemas relacionados ao SMS
- problemas relacionados ao link
- problemas durante assinatura
- recuperação de clientes que abandonaram o processo
- definição de quando o bot deve tentar novamente
- definição de quando o bot deve encaminhar para atendimento humano
- clareza e objetividade das respostas
- confirmação correta das etapas do processo
- prevenção de informações inventadas ou não confirmadas

Gere pelo menos 10 prompts de melhoria.

Para cada prompt, informe:

Prompt de melhoria:
[texto completo da instrução que poderia ser incorporada ao bot]

Problema identificado:
[qual comportamento atual precisa ser melhorado]

Objetivo:
[qual comportamento esperamos do bot após a melhoria]

Prioridade:
[Alta, Média ou Baixa]

Não crie prompts genéricos.
Cada prompt deve estar relacionado a um comportamento
observado nos dados reais.

Não invente comportamentos que não aparecem nos dados.
